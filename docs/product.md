# 제품 목적과 범위

## 목적

ECommerceAPI는 전자상거래의 핵심 사용자 흐름을 HTTP와 JSON으로 제공하는 API 중심 백엔드다. 사용자, 상품, 장바구니, 주문, 결제 데이터를 관계형 데이터베이스에 저장하고 도메인 규칙과 트랜잭션 일관성을 보장한다.

## 현재 구현 범위

### 인증과 권한

- 이메일 회원가입과 BCrypt 비밀번호 저장
- 이메일·비밀번호 로그인과 JWT access token 발급
- `USER`, `ADMIN` 역할
- 공개 상품 API, 인증 사용자 API, 관리자 전용 상품 API 구분

### 상품

- 활성 상품 목록·상세 조회
- 상품명 부분 검색과 페이지네이션
- 관리자용 전체 상품 목록·상세 조회
- 상품 생성, 이름·가격 수정, 재고 설정
- 상품 활성화와 비활성화

### 장바구니

- 현재 사용자의 장바구니 조회
- 상품 추가, 수량 변경, 제거
- 상품 활성 상태, 수량, 현재 재고 검증
- 사용자당 하나의 장바구니와 상품 중복 행 방지

### 주문

- 현재 장바구니를 기반으로 주문 생성
- 주문 상품명·가격 스냅샷과 주문 총액 저장
- 주문 목록·상세 조회
- 결제 대기 주문 취소
- 주문 생성 후 장바구니 항목 제거

### 결제

- 주문 소유자의 결제 시도 생성과 조회
- 결제 완료·실패·취소 상태 전이 시뮬레이션
- 결제 완료 시 재고 차감과 주문 `PAID` 전환
- 실패하거나 취소된 결제 이후 재시도

## 현재 비범위

- 실제 PG 또는 실제 금전 처리
- 카드·계좌 등 결제 수단 정보 저장
- refresh token, 토큰 폐기 저장소, 서버 측 로그아웃
- 배송, 환불, 쿠폰, 할인, 리뷰, 위시리스트
- 프런트엔드 또는 모바일 클라이언트
- 다중 판매자, 창고, 배송사 연동
- 마이크로서비스, 메시지 브로커, 검색 엔진
- 운영 배포 자동화와 운영 관측 시스템

현재 제한의 상세 내용은 `known-limitations.md`에 기록한다. 새로운 요구사항이 확정되면 이 문서의 현재 범위 또는 비범위를 갱신하고, 중요한 기술 선택은 ADR로 남긴다.
